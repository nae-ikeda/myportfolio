# WRAPLINE｜法人向け営業車ラッピング LP（自主制作）

ポートフォリオ用に制作した、架空のカーラッピング会社のランディングページです。
企業名・料金・事例はすべて架空のものです。

## 担当
企画・デザイン（Figma）・コーディング

## 使用技術
- HTML5
- SCSS（Dart Sass／FLOCSS風にパーシャル分割、BEM命名）
- JavaScript（ライブラリなし）

## デザインの考え方
法人の担当者に「任せて大丈夫そう」と感じてもらえるよう、海外の自動車・モビリティ系LPに多い編集デザイン風の見せ方を参考にしました。
- 余白を広くとり、大きな見出しと細い罫線で情報を区切る
- 配色は黒・オフホワイト・オレンジの3色にしぼる（オレンジはラッピングフィルムと安全色のイメージ）
- 番号つきのセクション見出し（01 — Problem など）で、読み進める順番をはっきりさせる
- ボタンは角ばった形にして、業務用サービスらしい硬さを出す

## 実装のポイント
- モバイルファーストのレスポンシブ対応（ブレイクポイント 600px／900px）
- PCでは見出しを左に固定（`position: sticky`）し、右側の内容だけがスクロールする2カラム
- 対応車種が横に流れる帯（CSSアニメーション。「視差効果を減らす」設定の環境では止まる）
- 最後の「Let's wrap.」は画面幅に合わせて文字サイズが変わる（`clamp()`）
- スマホ用ハンバーガーメニュー（`aria-expanded` で開閉状態を管理、Escキーで閉じる）
- よくある質問は `details`／`summary` でJSなしのアコーディオン
- お問い合わせフォームの入力チェック（必須・メール形式、エラーを読み上げ対応）
- 画像はSVGで軽量化、施工事例は `loading="lazy"`
- キーボード操作時のフォーカス表示

